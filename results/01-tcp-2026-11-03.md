## Question

Does the gate logic, the FMP counter boundary and the durable-eviction sequence
behave the same over TCP as over UDP? This is the first Phase 2 transport check.

## Setup

Two-node lab, same test identities as Exp C, transport changed to TCP:

```
seller (TCP :443, passive)  <---- TCP ---->  buyer (TCP, outbound-only)
```

The seller binds `0.0.0.0:443` and has no peer entries, so its ACL is the
admission gate. The buyer has no `bind_addr`, so it is outbound-only and dials
`seller:443`. Strict ACLs (`ALL` in `peers.deny`).

```sh
harness/exp-tcp/run-exp-tcp.sh
```

Traffic: 40 ICMPv6 frames with 1200-byte payloads. Same orchestration as Exp C,
with `--label tcp`.

## Interpretation

1. **The gate is transport-independent.** The same sidecar, ACL sequence,
   durable eviction and re-admission procedure pass over TCP. The state machine
   never needs to know which transport carries the link.
2. **TCP's bare reconnect is consistently about a second slower.** 7.71–7.86 s
   over four runs vs 6.50–6.92 s for UDP. This is a transport difference, not a
   one-off. TCP keepalive/framing are the likely causes; durable eviction and
   re-admission remain in the same few-second band.
3. **Metering still lands on FMP frame bytes.** The TCP counter is the sealed FMP
   frame, excluding 20 + 20 bytes of TCP/IP encapsulation. The byte totals are
   lower than the UDP run (`59,998` vs `78,548`), which is a framing/aggregation
   difference, not a different boundary. Do not compare these as throughput.
4. **Port 443 is a real motivation for P1.** The TCP lab uses 443, the UDP lab
   2121, and neither is part of the peer's identity. The endpoint advertisement
   (P1) is what lets one offer name both.
5. **The free-ride window is transport-independent.** A bare cut reconnects
   without payment on TCP too. Durable eviction is required on every transport.

## Caveats

- Four TCP runs. ACL numbers vary with tick phase (344–745 ms), so quote the
  reconnect and re-admit ranges, not a single ACL sample.
- The traffic byte totals differ from UDP because of framing/aggregation; the
  result is about the gate sequence, not throughput.
- No payment, no mint. "Re-admit" is an ACL allow plus a handshake.
- No beacon/endpoint advertisement yet; the address is static config.
- ICMP only.
